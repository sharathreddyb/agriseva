# AgriSeva

AgriSeva is a web-based agricultural marketplace that connects farmers with equipment owners and sellers.

The platform allows users to list agricultural machines, tools, and farming-related products for rent or sale. Farmers can browse listings, compare prices and ratings, check location and availability, and submit rental or purchase requests.

## Current Project Scope

- User registration and login
- Role-based access for farmers, owners, sellers, and administrators
- Agricultural equipment and product listings
- Rent and sale listing types
- Search, filtering, sorting, and pagination
- Rental booking and purchase request workflows
- Farmer land or delivery location capture
- Ratings and reviews
- Listing and user administration
